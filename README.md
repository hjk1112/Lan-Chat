# 微信 · 局域网 (LAN-Chat)

一个基于 Node.js + Socket.IO + WebRTC 的局域网即时通讯演示项目。完全离线运行，所有数据保存在本地。使用DeepSeek提供代码。
本项目仅供技术参考与演示使用并与腾讯无关，“微信”“QQ”仅是风格参考。

## ✨ 功能特性
- 💬 私聊 / 群聊 / @提及 / 引用 / 撤回等。
- 📞 语音通话 / 视频通话 (基于 WebRTC)，不稳定基本不能使用。
- 🧧 红包 / 钱包 / 转账模拟。
- 🌟 朋友圈 / 空间动态。
- 🎵 音乐库共享。
- 🛡️ 完善的防攻击与风控体系。
- 📱 移动端 / 桌面端自适应 UI。

## 🚀 快速开始

### 1. 安装依赖

下载node.js
https://nodejs.org

### 2.安装前置
在压缩包里打开终端，输入：
```bash
npm install
```

### 2.启动服务器
双击 start.bat
会打开终端或cmd或pwsh，这是服务端，不要关闭。

### 3. 访问应用
浏览器访问：http://localhost:3000 或 https://localhost:3000

### 注意：首次运行会自动在 ./files/ 目录生成自签名证书和相关数据文件。
如果要在局域网内的手机端或其它设备访问，请确保防火墙放行了 3000 端口;备用下载使用 3001 端口。

## 附加（将端口映射到域名）（这个方案是临时的，关闭cloudflared tunnel即链接失效）
如果要暂时给其它人使用，请看这里。（使用的是cloudflared tunnel）
可以重复重新打开，域名随机，但免费。

### 1.下载前置
前往Github下载：https://github.com/cloudflare/cloudflared/releases/
下载最新的就行。将下载的.exe文件放到与node.exe(便携版）或server.js（安装版本）的同目录下。

### 2.确认服务器启动以及端口可以访问。
浏览器访问：http://localhost:3000 或 https://localhost:3000

### 3.映射端口
在项目目录（与server.js同目录）打开终端，输入：
cmd:
```bash
cloudflared tunnel --url https://127.0.0.1:3000 --no-tls-verify
```
pwsh:
```bash
.\cloudflared tunnel --url https://127.0.0.1:3000 --no-tls-verify
```
注：https://127.0.0.1:3000 为本地可访问的地址。
--no-tls-verify 为取消本地链接的证书认证（自签名证书使用这个）。

终端打印的地址就可以访问（这个是随机的，关闭命令行即失效）：
-------------------------------------
xxx.trycloudflare.com
