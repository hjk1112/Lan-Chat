# 微信 · 局域网 (LAN-Chat)

一个基于 Node.js + Socket.IO + WebRTC 的局域网即时通讯演示项目。完全离线运行，所有数据保存在本地。使用DeepSeek制作。

## ✨ 功能特性
- 💬 私聊 / 群聊 / @提及 / 引用 / 撤回
- 📞 语音通话 / 视频通话 (基于 WebRTC)，不稳定。
- 🧧 红包 / 钱包 / 转账模拟
- 🌟 朋友圈 / 空间动态
- 🎵 音乐库共享
- 🛡️ 完善的防攻击与风控体系
- 📱 移动端 / 桌面端自适应 UI

## 🚀 快速开始

### 1. 安装依赖
```bash
npm install

2.启动服务器
双击 server.bat

3. 访问应用
浏览器访问：http://localhost:3000 或 https://localhost:3000

注意：首次运行会自动在 files/ 目录生成自签名证书和相关数据文件。
如果要在局域网内的手机端访问，请确保防火墙放行了 3000 端口。
